# Unions that overlay a scalar integer on bit-fields and carry no size assert, with the reason
# each one is safe anyway. bin/check_bitfield_overlay_unions.py reads this file; everything else
# it finds either has a static_assert on the type's size or fits the overlay provably.
#
# A line is:   <path>:<type>:<overlay member>:<width of the first bit-field> <fingerprint>  # reason
#
# The fingerprint covers the declared type and width of every bit-field and the type of the
# overlay. Add, remove or retype a member and it stops matching, so the gate asks again instead
# of trusting a decision taken for a different union. Get the new line from
#   python bin/check_bitfield_overlay_unions.py --emit-allow
# and only then write the reason, after re-checking the layout.
#
# Nearly every line below is one shape: a union of SEVERAL alternative named structs (one per
# chip generation, or one per endianness through #if), where each alternative is exactly as wide
# as the overlay. The gate counts the bit-fields of all of them together, which is deliberate:
# it would rather ask than model the preprocessor.
